# FDT 辩论报告排版规范

> 创建时间：2026-07-22
> 来源：掌柜确认的 fdt-debate-cf2609-ta609-l609.html 排版风格

## 一、排版原则

FDT 辩论分析报告输出（HTML）遵循以下设计原则：

1. **深色页眉 + 白色内容区**的明暗对比
2. **粘性导航栏**便于长报告跳转
3. **阶段标签（Phase Badge）**：P1红色/P1.5蓝色/P3黄色/P4红色/P5绿色
4. **三列指标体系**：品种关键价格用三列并排展示，含涨跌色标
5. **info-grid 网格布局**：2-3列自适应网格展示技术/基本面维度
6. **辩论框（Debate Box）**：多头用红色左边框+浅红底，空头用蓝色左边框+浅蓝底
7. **判决框（Verdict Box）**：深色渐变背景+白色文字
8. **风控框（Risk Box）**：绿色/黄色/红色三种等级

## 二、色彩系统

- --bg: #f4f2ed（暖灰背景）
- --bg2: #ffffff（纯白内容区）
- --ink: #1a1a1e（深黑灰正文）
- --muted: #6b6b72（中灰次要文字）
- --rule: #d8d6d0（浅灰分割线）
- --accent: #c44536（砖红强调色/空头色）
- --accent2: #2b6c7e（深蓝绿次要强调/多头色）
- --green: #2d7d4f（墨绿涨/通过）
- --red: #c44536（砖红跌/警告）
- --yellow: #c49a2b（金黄观望/关注）

## 三、排版组件

| 组件 | 用途 |
|:-----|:-----|
| report-header | 深色渐变+白字 报告标题区 |
| nav-bar | 白底+sticky粘性导航 章节跳转 |
| phase-badge | 彩色背景圆角标签 阶段标识 |
| metrics-summary | 三列grid卡片 品种价格速览 |
| info-grid | auto-fit自适应网格 维度展示 |
| debate-box.bull | 红左边框+浅红底 多头论点 |
| debate-box.bear | 蓝左边框+浅蓝底 空头论点 |
| verdict-box | 深色渐变+白字+评级标签 闫判官裁决 |
| risk-box | 三色框 风控审核结果 |
| callout | 左accent边框渐变背景 核心矛盾小结 |

## 四、章节顺序

1. 数据总览（P1数技源扫描）
2. 链证源产业链分析（P1.5）
3. 观澜技术面分析（P2）
4. 探源基本面分析（P3）
5. 多空头六阶段攻防辩论（P3）→ 立论x2 → 反驳x2 → 结辩x2
6. 闫判官终裁（P4）含完整交易参数
7. 风控明审核（P5）红线table+结论
8. 最终交易建议（明鉴秋汇总）

## 五、使用说明

响应式设计，768px断点grid降单列。字体优先Noto Sans CJK SC。图表使用ECharts SVG渲染，颜色引用CSS变量。
