# 大宗商品轮动规律与康波周期驱动：复合型通胀下的牛市框架

> 来源：微信公众号 | 永安系投研团队
> 框架来源：长江证券+永安系+康波周期（周金涛）
> 关联：高盛方法论、库存周期框架、工业品比价

## 行情发动的两种类型

| 类型 | 发动机 | 刹车 | 特征 | 案例 |
|:-----|:------|:-----|:-----|:-----|
| **需求拉动型** | 需求持续扩张 | 供给跟进或需求回落 | 温和上涨后加速，持续时间长 | 2000s中国工业化 |
| **成本推动型** | 供给突然收缩 | 供给恢复或需求被高价打掉 | 更猛烈但更短暂 | 1973/1979石油危机 |
| **复合型通胀（当前）** | 供给刚性+需求扩张双向叠加 | 待定 | 价格弹性更大，持续时间更长 | 2023-2026 |

## 大宗商品轮动顺序（长江证券框架）

### 贵金属 → 基本金属 → 能源 → 化工 → 农产品

底层逻辑链：**谁对流动性最敏感→谁最先动；谁对实体复苏最敏感→紧跟；谁对通胀最敏感→最后动。**

| 板块 | 启动时间 | 核心驱动 |
|:-----|:--------|:--------|
| 贵金属（金/银） | 最先 | 流动性宽松+美元信用动摇 |
| 基本金属（铜/铝/锂） | 跟进 | 实体复苏预期+资本开支不足+AI结构性需求 |
| 能源（原油/天然气） | 中段 | 需求确认回升+地缘冲突 |
| 化工 | 中后段 | 油价成本推动+自身供需节奏 |
| 农产品 | 最后 | 与CPI直接相关，政策最敏感 |

## 2023-2026年本轮牛市进程

- **2023** — 贵金属主导：央行购金+美元信用动摇
- **2024-2025** — 基本金属/稀有金属：AI资本开支+铜铝锂结构性需求
- **2026上半年** — 能化+农产品：美伊冲突→霍尔木兹封锁→油价大涨→成本传导
- **2026下半年（预期）** — 农产品可能接力：厄尔尼诺+化肥/能源成本+库销比变化

## 康波周期对有色的驱动

康波萧条期 → 资本开支缩减 → 矿企推迟新项目 → 建设周期5-10年 → 供给持续收紧

| 品种 | 供给约束 | 需求增量 |
|:-----|:---------|:---------|
| 铜 | 矿山资本开支2010s末见顶，无新绿地项目 | AI数据中心（2030年新增100万吨/年）+电动车+光伏 |
| 铝 | 欧洲能源危机关停+中国产能天花板 | AI电力传输+配电设施 |
| 锂 | 2022-2023暴跌导致项目推迟 | 电动车+储能+AI算力储能 |

> 窗口期未来2-3年，高价格刺激的新增供给会逐步投产。**不是在交易康波长牛，而是在交易供给收缩遇上需求结构性扩张的阶段性机会。**

## 农产品的三重驱动

| 驱动 | 传导路径 |
|:-----|:---------|
| 化肥成本 | 天然气→尿素→农民成本→产量 |
| 能源成本 | 汽柴油→机耕费/运费→全产业链成本 |
| 天气周期 | 厄尔尼诺/拉尼娜→主产区单产波动 |
| 能源替代（新） | 油价高→生物燃料经济性→玉米制乙醇 |

> 某种意义上，农产品已经是"液体的燃料"。
